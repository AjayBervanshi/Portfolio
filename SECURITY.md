# ?? Security Policy

## Supported Versions
Only the latest release on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability
We take the security of our codebases seriously. If you believe you have discovered a vulnerability, please report it privately:

1. **Do not** open a public GitHub issue.
2. Contact the maintainer directly via GitHub or private email.
3. Include detailed steps to reproduce the vulnerability and potential impact.

We will acknowledge receipt within 48 hours and work expeditiously on a patch.
